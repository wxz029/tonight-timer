# Tonight Timer 1.1.0 / 今晚还有多久 1.1.0

## 中文

这是一个显示“距离睡觉还有多久”和“今晚还可以学习多久”的 Windows 桌面小组件。

本次更新：

- 新增完整的中文 / English 界面切换。
- 主界面、设置、状态提示、工具提示和托盘菜单均已双语化。
- 正确计算次日 01:00 等跨午夜睡觉时间。
- 安装包发布者与版权信息已完成配置。

下载选择：

- `TonightTimer-Setup-1.1.0-x64.exe`：安装版。
- `TonightTimer-Portable-1.1.0-x64.exe`：免安装便携版。

## English

A Windows desktop widget that shows the time remaining until bedtime and the study time still available tonight.

What's new:

- Added complete Chinese / English interface switching.
- Localized the widget, settings, status messages, tooltips, and tray menu.
- Correctly handles after-midnight bedtimes such as 01:00 tomorrow.
- Publisher and copyright metadata are included in the installer.

Downloads:

- `TonightTimer-Setup-1.1.0-x64.exe` — installer.
- `TonightTimer-Portable-1.1.0-x64.exe` — portable version.

> The app is not signed with a paid code-signing certificate. Windows SmartScreen may show “Unknown publisher” on first launch.
